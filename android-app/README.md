# TCG Boogie for Android

The Google Play app: a Trusted Web Activity that opens tcgboogie.com full-screen (start page `/app/home`). It is
generated by Google's Bubblewrap from the site's manifest (`web/app/manifest.js`) into `twa-manifest.json` and this
Gradle project. Site changes reach the app on their own; only changes to the app shell (name, icon, colors, package,
shortcuts) need a new build and upload.

- Package: `com.tcgboogie.app` (permanent once on Google Play).
- Signing (upload) key: `C:\Users\Chris\.tcgboogie\android-upload.jks`, alias `upload`. It stays outside the repo and
  is never committed. Keep a copy somewhere safe (e.g. a password manager) with its password: losing it means asking
  Google for an upload-key reset.
- Tools: Bubblewrap (`npm.cmd install -g @bubblewrap/cli`), which keeps its own Java 17 and Android SDK in
  `C:\Users\Chris\.bubblewrap`.

## Build

From this folder, in PowerShell:

```
Remove-Item Env:NoDefaultCurrentDirectoryInExePath -ErrorAction SilentlyContinue; bubblewrap.cmd build
```

(This PC sets NoDefaultCurrentDirectoryInExePath, which stops Bubblewrap finding `gradlew.bat`; the first part turns
it off for that window only. The build needs a few GB of free memory: close games first if it says the Gradle daemon
disappeared.)

It asks for the key's passwords and writes `app-release-bundle.aab` (upload this to Play) and `app-release-signed.apk`
(install on a phone to try). Before each new upload, raise `appVersionCode` (and `appVersionName`) in
`twa-manifest.json` and run `bubblewrap.cmd update` first.

## Full-screen check (Digital Asset Links)

The app hides Chrome's address bar only when `https://tcgboogie.com/.well-known/assetlinks.json` lists the app's
signing keys. That file is `web/app/api/assetlinks/route.js` (FINGERPRINTS). Add both:

1. The upload key: `bubblewrap.cmd fingerprint generateAssetLinks` or `keytool -list -v -keystore <key> -alias upload`.
2. Google's app signing key: Play Console -> the app -> Test and release -> App integrity -> App signing (SHA-256).

## Getting onto Google Play (personal account)

1. Sign up at play.google.com/console ($25 once, ID check).
2. Create the app "TCG Boogie" (App, Free), fill in the store listing, content rating, data safety, privacy policy
   (https://tcgboogie.com/privacy) and account deletion (https://tcgboogie.com/app/account#delete).
3. Closed testing: upload the `.aab`, add at least 12 testers (their Google account emails), and keep them opted in for
   14 days. Then apply for production access.
